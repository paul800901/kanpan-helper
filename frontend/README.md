# 看盤助手前端 v3

## 檔案結構

```
frontend/
├── index.html      # 主頁面
├── style.css       # 樣式表
├── app.js          # 應用程式邏輯
├── sample/         # 測試用報告
│   └── 2026-04-08-lite.json
└── README.md       # 本檔案
```

## 使用方法

### 方式一：直接開啟（使用 sample 資料）

```bash
# 進入 frontend 資料夾
cd frontend

# 使用 Python 簡易伺服器
python -m http.server 8080

# 瀏覽器開啟
http://localhost:8080
```

### 方式二：讀取實際報告

確保 `../reports/YYYY-MM-DD-lite.json` 存在，然後開啟頁面。

### 方式三：指定日期

```
http://localhost:8080?date=2026-04-08
```

## 測試情境

### 正常載入
- 預設會讀取當天日期的報告
- 若找不到，會顯示錯誤提示

### 測試錯誤狀態
1. 修改網址參數指向不存在的日期：
   ```
   ?date=1999-01-01
   ```
2. 應該會顯示「找不到報告檔案」的錯誤 Modal

### 測試篩選功能
頁面上方有 5 個篩選按鈕：
- 全部
- 可留意
- 觀察
- 偏保守
- 暫不考慮

點擊後會即時過濾股票卡片。

## 卡片展開內容

點擊卡片後會展開：
- 選股理由（白話）
- 風險提醒（紅色標示）
- 技術數據（收盤價、成交量比、趨勢、法人動向）

## 注意事項

- 本前端為靜態頁面，不需要後端伺服器
- 但需要使用 http/https 協定（非 file://）才能讀取 JSON
- 建議使用 Python 簡易伺服器或 VS Code Live Server 測試
